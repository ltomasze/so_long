The so_long project is one of the initial assignments in the 42 school curriculum, focusing on creating a simple 2D game using the MiniLibX (MLX) graphics library.<br> The objective of the game is to navigate through a map, collect all available items, and reach the exit while avoiding obstacles.<br>​

Game Description<br> The player controls a character on a top-down map using the W, A, S, and D keys to move up, left, down, and right, respectively.<br> The map is represented in a .ber file, where:<br>​

1 denotes walls (impassable)<br>

0 represents empty spaces<br>

C indicates collectibles (items to be gathered)<br>

E marks the exit of the map<br>

P signifies the player's starting position<br>​

The game is successfully completed when the player collects all items and reaches the exit.<br>​

Compilation and Execution<br> To compile the project, use the command:<br> make<br> Then, run the game with:<br> ./so_long maps/example.ber<br> Ensure that the MiniLibX library is correctly installed and accessible within the project.<br>​

The so_long project serves as an excellent introduction to game programming, computer graphics, and event handling in the C language, enhancing skills in memory management, input processing, and graphics rendering.<br>

Projekt so_long to jedno z pierwszych zadań w ramach programu szkoły 42, polegające na stworzeniu prostej gry 2D z wykorzystaniem biblioteki graficznej MiniLibX (MLX).<br>
Celem gry jest poruszanie się po mapie, zbieranie wszystkich dostępnych przedmiotów i dotarcie do wyjścia, przy jednoczesnym unikaniu przeszkód.<br>​

Opis gry <br>
Gracz steruje postacią na mapie z góry, używając klawiszy W, A, S, D do poruszania się w górę, lewo, dół i prawo.<br> Mapa jest reprezentowana w pliku .ber, gdzie:<br>
1 oznacza ściany (nieprzekraczalne)<br>
0 to puste przestrzenie<br>
C to przedmioty do zebrania (collectibles)<br>
E to wyjście z mapy<br>

P to początkowa pozycja gracza<br>​

Gra kończy się sukcesem, gdy gracz zbierze wszystkie przedmioty i dotrze do wyjścia.<br>​

Kompilacja i uruchomienie<br>
Aby skompilować projekt, użyj polecenia:<br> 
make<br>
Następnie uruchom grę za pomocą:<br>
./so_long maps/example.ber<br>
Upewnij się, że biblioteka MiniLibX jest poprawnie zainstalowana i dostępna w projekcie.<br>​

Projekt so_long stanowi doskonałe wprowadzenie do programowania gier, grafiki komputerowej oraz obsługi zdarzeń w języku C, rozwijając umiejętności w zakresie zarządzania pamięcią, przetwarzania danych wejściowych i renderowania grafiki.<br>
